# 成本预算助手与双资产协同执行

这两个功能位于本地面板第06区，分别展开“成本预算助手”和“双资产协同执行”。不需要上传行情；全部行情、成交量、价差、费用和相关系数都是明确设置的人工假设。它们是机制实验，不能作为真实交易优势或盈利证据。

## 成本预算助手

输入卖出数量、起始中价、最长交易时间、预期每分钟成交量、价格波动、完整价差、单边费用、冲击参数、参与率、预算和要求的达标比例。

程序比较最长时间的四分之一、二分之一、四分之三和全部时间（向上取整），每个时长分别尝试均匀分批和前快后慢，共8个预定候选。前快后慢的权重从2线性减至0.5。计划在交易开始前确定；到期积压可在后续分钟继续尝试，但不超过已释放数量和截止时间。

- 每分钟价格使用零预期漂移的对数正态模型；价格收益波动以每分钟基点计。
- 成交量按固定U形预期轮廓，叠加日级和分钟级对数正态扰动，再向下取整。它不是从真实分钟数据估出的成交概率。
- 成交量上限 = 本分钟外部成交量 × 参与率，使用十进制乘法向下取整。
- 单股临时冲击 = 当时中价 × 冲击参数/10000 × 本分钟实际成交参与比例。
- 到达价缺口 = 起始中价对应的已成交名义金额 − 卖出净收入，包含时机、半价差、费用与临时冲击。
- 成本基点 = 到达价缺口 / 整笔订单起始名义金额 × 10000。负值仅表示相对起始中价卖得更好，不是投资利润。

**联合达标必须同时满足：截止前全部完成、到达价缺口不超过预算。** 未完成、已完成但超预算、完成且达标构成互斥且完整的三类，不删除失败情形。预算只用于规划与事后评估，不会触发实际硬止损，也不保证每条路径成本受限。

规划集256条路径，独立验证集256条路径。候选在各自集合内共享同一条市场路径，以便配对比较；两组使用不同随机流。只根据规划集挑选：先筛出达到要求的候选，再选时长最短者，同时间按规划条件P95和均值破同分。验证结果不会反过来修改推荐。没有候选达标时明确返回“本次候选没有满足”，不宣称数学上无解。

表中的“规划时长/达标前沿”指在规划集中，没有其他候选同时做到时长不更长、联合达标比例不更低，且至少一项更好。它是这两个指标的前沿，不是成本或全局最优证明。

各候选的完成路径P95来自各自的条件样本，不能直接跨候选作严格成本排名。共同完成成本用所有8个候选都完成的同一组路径比较，并报告数量；数量为0时显示空值。其他候选不完成不应被隐藏。

## 双资产协同执行

任务固定为同币种卖出A、买入B；支持数量、两边起始价格、初始现金、截止时间、参与率、共同波动尺度、收益相关系数、费用、价差、冲击、风险权重和预测进度差目标。

人工情形包括均衡、B买入侧前段流动性较低、A卖出侧前段流动性较低，以及两边均无成交容量。低流动性阶段为前60%的分钟；预期基准成交量1200股/分钟，低流动性侧成交量除以8。相关系数和模型波动已知是假设，不是通过未来数据估计。

每条路径，两种方法使用相同订单、市场价格、外部成交量、成本参数和成交上限。两笔独立执行按累计均匀进度尝试，并追赶积压。协同执行在有限的候选子单组合中：
1. 用过去最多5分钟平均成交量预测容量，首分钟使用1200股的显式先验；只看当前价格，不看当分钟及未来成交量。
2. 预测先卖A、再用到账资金买B，优先减少预测进度差超出目标的部分。
3. 在相同预测超限程度下，最小化：本步直接成本 + 风险权重 × 下一步目标偏离风险标准差 + 0.025 × 起始双边总名义金额 × 落后计划的比例平方和。
4. 实际成交仍受本分钟事后容量及可用现金限制，因此实际进度差可能超过预测目标。风险权重为0时，完全使用独立方案。

候选包括等待、累计均匀需求、预测容量、剩余均摊速度的两倍，以及预测进度差边界。它是单步反馈启发式，不是动态规划或全局最优求解。进度差优先级可能牺牲成本或完成程度，不能保证两边同时成交。

数量使用整数股。价格与现金精确到分；价差、费用、冲击合计向上取整到分。买入金额用单调二分核对可支付的整数股数。不借款、不做空、不超过目标数量。**卖出资金当分钟可用于买入是假设，尚未模拟实际结算、券商资金限制、汇率、跨市场时钟或交易所撮合。**

目标偏离向量为 d = (剩余A股数 × A中价, −剩余B股数 × B中价)，相对的是最终目标组合。每分钟风险方差为 σ²(dA² + dB² + 2ρdA dB)，两腿共用一个波动尺度。风险积分是分钟末方差之和，单位为货币²·分钟；不是已发生损失。最大进度差为两边已完成比例差的绝对值。

32条人工路径均保留，展示两边同时完成的比例、两边余量、风险积分、峰值、进度差、现金约束及尾部成本。已成交全量成本仅比较两种方法共同完成的同一组路径。成本基点分母为双边起始总名义金额，不能与单边成本基点直接等同。未完成余量的期末中价机会成本另标记为诊断，不视作成交。

图表与逐分钟现金账本只回放输入种子的第一条路径，表格统计则来自全部32条路径。它们不是32个真实交易日。正负相关、初始资金及流动性变化会显著改变结果。

## 报告、数据与验证

两种实验复用后台任务、状态查询和第07区报告入口；支持离线HTML、Markdown及完整JSON依据。报告读取已保存记录并附SHA-256指纹。所有运行输出写入启动时指定的仓库外目录，不自动提交GitHub；原有冻结结果和核心计算保持不变。

自动检查覆盖已知成本公式、联合事件分母、独立选方案、数量与现金守恒、未来数据扰动、零容量、资金不足、HTTP类型隔离、报告下载和过期页面响应。人工测试通过只证明这些机制按当前假设工作，不能代替报价数据、真实成本校准和更长市场验证。

多资产成本与风险权衡可参考 [Boyd等：Multi-Period Trading via Convex Optimization](https://web.stanford.edu/~boyd/papers/cvx_portfolio.html)。本模块仅为有限候选启发式，没有复现该论文的凸优化算法。代码和研究整理使用AI辅助。
