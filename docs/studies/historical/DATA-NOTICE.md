# Data notice

Source: European Central Bank (ECB), euro foreign exchange reference-rate historical CSV archive.

- [Official source and methodology](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)
- [Download](https://www.ecb.europa.eu/stats/eurofxref/eurofxref-hist.zip)
- [ECB reuse conditions](https://www.ecb.europa.eu/services/using-our-site/disclaimer/html/index.en.html)

The original archive is retained unmodified. Derived cross-rates, date filtering, sorted rows, log returns, volatility fits and other statistics are researcher modifications, with no ECB endorsement implied. Data-source conditions are separate from any future code license.

Retrieval timestamp, URL, snapshot hashes and response metadata are in inputs/source/source-metadata.json. This is a current historical snapshot, with no point-in-time vintage guarantee. Reference prices are informational and are not executable transaction quotes. All model outputs remain research demonstrations under disclosed assumptions.
